# 小说设定写作工具

这是一套专为小说创作设计的设定模板集合，帮助您系统地构建人物、世界观和剧情。

## 文件说明

### 核心模板文件

1. **01-人物设定.txt** - 人物设定模板
   - 基本信息、外貌特征、性格特点
   - 背景经历、能力技能、人际关系
   - 人物弧光规划

2. **02-世界观设定.txt** - 世界观设定模板
   - 世界概览、地理环境、社会结构
   - 文化习俗、科技魔法体系
   - 历史背景、生态系统

3. **03-剧情大纲.txt** - 剧情大纲模板
   - 核心概念、主要角色、故事结构
   - 分章分卷规划
   - 关键情节、伏笔收线

4. **04-设定关联索引.txt** - 设定关联索引
   - 人物关系网、地点与事件关联
   - 事件时间线、物品道具索引
   - 关键词索引

### 示例文件

- **examples/人物-张三.txt** - 人物设定示例

## 使用建议

1. 按顺序填写：先人物，再世界观，最后剧情
2. 保持文件命名规范，便于查找
3. 定期更新关联索引，保持设定一致性
4. 可根据需要复制模板创建更多设定文件
5. 所有模板都可根据您的需求灵活调整
